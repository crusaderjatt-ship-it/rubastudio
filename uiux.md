# Ruba Studio – UI/UX Specification

## Design Goal
The app should feel simpler than Instagram.

No prompt engineering.
No complex forms.
No technical language.

## Navigation
Bottom tabs:
1. Create
2. Gallery
3. Favorites
4. Settings

## Create Flow
Screen 1: Upload Outfit
- Big upload button
- Camera/gallery support

Screen 2: Choose Look
- Model: Ruba selected by default
- Pose chips:
  - standing
  - walking
  - smiling
  - hand under chin
  - looking back
- Backdrop chips:
  - Chandigarh garden
  - brick wall
  - street
  - courtyard
  - studio
- Generate button

Screen 3: Results
- Show 4 generated images
- Tap to preview
- Favorite button
- Regenerate button
- Edit with quick actions:
  - change footwear
  - smile more
  - change background
  - make full body
  - keep same face

Screen 4: Share
- Generate caption
- Generate hashtags
- Download
- Share to Instagram via native share sheet

## UX Principle
One screen should have one main action only.
