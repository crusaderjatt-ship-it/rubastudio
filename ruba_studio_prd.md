# Ruba Studio – Product Requirements Document

## Product Vision
Ruba Studio is a private, installable PWA for creating Instagram-ready fashion photos from outfit images.

The app is designed first for one private user: the user's wife.

## Core Promise
Upload dress photo → generate beautiful fashion images → pick best one → share to Instagram.

## Target User
Primary user:
- Private family use
- Simple mobile-first experience
- No prompt writing required

## MVP Workflow
1. Open Ruba Studio on phone
2. Login privately
3. Upload dress/outfit photo
4. Choose model: Ruba
5. Choose simple options:
   - pose
   - backdrop
   - expression
   - footwear
6. Generate 4 images
7. Select favorite
8. Generate caption + hashtags
9. Download or share to Instagram

## MVP Features
- Private login
- Mobile-first PWA
- Outfit upload
- AI outfit understanding
- Ruba model consistency
- Simple preset-based generation
- Gallery
- Favorites
- Caption generator
- Hashtag generator
- Native share button
- Download image to phone

## Non-Goals for MVP
- Public SaaS marketplace
- Multi-user teams
- Payment system
- Complex admin panel
- Video generation
- E-commerce export

## App Name
Ruba Studio
