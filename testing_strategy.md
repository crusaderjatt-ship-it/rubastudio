# Ruba Studio – Testing Strategy

## Functional Tests
- User can login
- User can upload outfit
- User can generate images
- User can favorite image
- User can generate caption
- User can download/share image

## AI Quality Tests
Check generated output for:
- Ruba face consistency
- outfit fidelity
- correct bottom type
- correct footwear
- realistic hands
- realistic face
- correct backdrop
- no unwanted signboard

## Mobile Tests
- iPhone Safari
- Android Chrome
- PWA install
- Camera upload
- Share sheet
- Download behavior
