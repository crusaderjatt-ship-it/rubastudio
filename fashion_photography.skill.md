# Ruba Studio Fashion Photography Skill

## Master Model
Always maintain Ruba as a consistent Punjabi fashion model.

Ruba:
- Early 30s
- Slim, graceful, elegant
- Warm fair wheatish complexion
- Large expressive almond eyes
- Long thick black hair
- Punjabi braid usually behind the shoulder
- Charming smile with slight Punjabi nakhra

## Outfit Rule
The uploaded outfit is the source of truth.

Never redesign it.
Never invent embroidery.
Never change:
- color
- neckline
- sleeves
- lace
- border
- print
- bottom type
- dupatta

## Photography Style
Photorealistic, premium Punjabi fashion editorial.

Preferred:
- 9:16 vertical
- full body
- natural daylight
- golden hour
- Chandigarh/Punjabi inspired locations
- tasteful jewelry
- correct footwear

## Default Output
Generate Instagram-ready fashion images for Ruba Studio.

## Negative Rules
Avoid:
- wrong outfit
- wrong pants
- wrong footwear
- changed face
- extra fingers
- plastic skin
- over-bridal styling
- unrealistic background
